Tentang Saya

Cerita singkat dari SMK RPL sampai kuliah Teknik Informatika.

Profil Singkat

Saya memulai perjalanan di bidang pengembangan perangkat lunak sejak SMK jurusan Rekayasa Perangkat Lunak (2020–2023). Proyek awal yang saya kerjakan adalah pembuatan web portofolio serta aplikasi kasir desktop menggunakan VB dan C#. Selama SMK, saya juga menjalani magang industri di Software House JV Partner Malang sehingga terbiasa dengan alur kerja tim di lingkungan industri.

Melanjutkan studi di Teknik Informatika angkatan 2023, saya aktif mengerjakan proyek kampus dan mengikuti kompetisi. Pada semester 1–2, aplikasi kasir apotek desktop yang saya bangun meraih Juara 1 SISKA dan Juara Poster Aplikasi EPIM. Selanjutnya, saya meraih Juara 3 kategori Aplikasi Web & Mobile melalui E-Surat Badean (sistem surat Kelurahan Badean, Bondowoso), serta Juara 3 KMIPN kategori E-Government melalui aplikasi Smart Mosquito Cam (AI).

Saat ini di masa kuliah, saya menjalani magang di OTW Computer Gusaha dengan mengerjakan aplikasi analisa keuangan & kelayakan kredit berbasis AI, sekaligus menyusun artikel jurnal ilmiah yang saat ini berada dalam tahap proses review. Ke depan, saya berfokus memperdalam jalur Full-Stack Web Development (Laravel, REST API, MySQL) sekaligus mengembangkan kemampuan integrasi mobile dan AI.
